The Brim package registry is live

Brim packages now have a home at registry.brimlang.com. Add a package to brim.toml by version and brim resolves it, downloads it and records the exact version in brim.lock. Publishing your own package takes one command.

Publish a package Use packages
brim.toml
[package]
name = "orders"
version = "0.1.0"
license = "Apache-2.0"

[dependencies]
router = "1.2"
Terminal
$ brim login
$ brim publish
published orders 0.1.0 to https://registry.brimlang.com

Build reliable backend services and tools

Brim is an open source, statically typed programming language from Ordnary. It has no null and no exceptions, runs on an interpreter during development and compiles to native code with LLVM.

Get started Download

macOS and Linux

curl -fsSL https://brimlang.com/install.sh | sh

Windows (PowerShell)

irm https://brimlang.com/install.ps1 | iex

Homebrew

brew install ordnary-com/tap/brim

What you can build with Brim

Brim is designed for the programs that run a business: services that answer requests, tools that run in a terminal or a pipeline, and the API between a backend and its web frontend.

Backend services

An HTTP server and client, a PostgreSQL client, JSON and logging are part of the standard library. Programs compile to a single native executable that fits in a small container image.

std.httpstd.postgres

Command-line tools

Read files and directories, run other programs and parse arguments. Ship one executable for Linux, macOS or Windows, with no runtime to install.

std.fsstd.process

Typed web APIs

Write an API as plain functions and serve them with serve_api. brim gen ts --angular generates the TypeScript types and an Angular client from the same code.

Why Brim

Brim keeps the small, readable syntax of languages like Go and adds the checks that catch common bugs at compile time instead of in production.

No null values

A value that may be absent has the type Option[T]. The compiler does not allow it to be used as a plain value.

Option and Result

Exhaustive matching

Enums carry data, and every match must handle every case. Adding a variant shows each place that needs an update.

Enums and match

Errors as values

Functions that can fail return a Result. The ? operator passes an error to the caller; it cannot be ignored silently.

Errors and ?

Checked arithmetic

Integer overflow stops the program with an error that points to the expression and shows the call stack.

Numbers

Clear compiler messages

Every diagnostic has a code, points to the source and explains how to fix the problem. Editors show the same messages through the language server.

Diagnostic codes
